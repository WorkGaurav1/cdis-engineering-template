# Adding a Feature

This guide outlines the process for introducing a new feature to the project.

## Suggested workflow

1. Define the feature boundary and domain responsibilities
2. Add frontend routes, pages, and components if required
3. Add backend routes, services, and data access as needed
4. Document the feature in the relevant architecture docs
5. Add tests for the key behavior

## Notes

Keep feature implementation aligned with the repository’s platform and feature architecture.
