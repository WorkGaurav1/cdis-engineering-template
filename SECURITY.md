# Security Policy

## Reporting a vulnerability

Don't open a public GitHub issue for a security vulnerability. Email **gauravbisen999@gmail.com** with a description and, if possible, steps to reproduce. Expect an initial response within a few business days.

## What's in scope

This repository and its three sibling repos (`cdis-frontend`, `cdis-backend`, `cdis-deployment`).

## Current security posture

See [`docs/standards/security.md`](docs/standards/security.md) for what's actually implemented (authentication, authorization, CSRF, rate limiting, security headers, secrets handling) — this file is the reporting process, that one is the control inventory.
